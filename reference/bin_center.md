# Bin Score and Assign center value

The `bin_center()` function takes a vector of scores between 0-1 and a
number of bins an returns the center of the bin the score falls in.

## Usage

``` r
bin_center(score, n_bins)
```

## Arguments

- score:

  The scores (values from 0-1) that are being binned

- n_bins:

  the number of bins the score

## Value

the center of the score bin for all scores
