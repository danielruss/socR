# noc2011 4 digit classification system

Canadian 4 digit National Occupational Classification (NOC) 2011

## Usage

``` r
noc2011_4digit
```

## Format

- noc_code:

  a 4 digit code formated like '0011', be careful must be a string not
  an integer

- title:

  a short definition of the code
